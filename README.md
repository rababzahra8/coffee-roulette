# Coffee Roulette ☕

A premium web app built for the **MLH challenge** that matches you with random coffee recipes based on the ingredients you have.

**Every coffee starts with a surprise.**

## Quick Start

```bash
cd coffee-roulette
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · Framer Motion · React Router

See [`coffee-roulette/README.md`](./coffee-roulette/README.md) for full documentation.
